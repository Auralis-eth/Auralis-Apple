# ADR-007: AuraPlay Linking Uses Custom Scheme For v1

Date: 2026-07-20  
Status: Accepted

## Context

AuraPlay needs links for sharing local music-library destinations: playlists, music collections, creator profiles, and individual media provenance. The app already declares the `auraplay` custom URL scheme and validates it through `AuraPlayModuleConfiguration`.

True HTTPS universal links require a hosted `apple-app-site-association` file on a controlled HTTPS domain. AuraPlay does not currently have a backend or hosted web presence, and Phase 12 explicitly avoids creating one.

## Decision

For v1, AuraPlay uses custom-scheme links as the primary app deep-link mechanism:

- `auraplay://playlist/{id}`
- `auraplay://collection/{contract-or-key}?chain={chainRawValue}`
- `auraplay://creator/{identifier}`

Individual NFT media shares should prefer public explorer URLs generated by the app's existing explorer policy. AuraPlay deep links are for local app destinations that do not have public web equivalents, especially playlists.

HTTPS universal links are deferred until the team chooses and operates a controlled domain with a valid static AASA file. A static host is acceptable; an application backend is not required just to serve AASA. Until that exists, Phase 12 must not emit HTTPS links that pretend to be universal links.

## Consequences

- Shared playlist links only resolve on devices where Auralis is installed and the referenced local playlist exists.
- Recipients without the app still receive useful plain text context from the share sheet, but no hosted playlist preview.
- Deep-link handling stays inside the existing shell path: `MainAuraView.onOpenURL`, `AppDeepLinkParser`, `ShellStore`, shell routing effects, and `AppRouter` navigation methods.
- `AppRouter` remains a navigation store and does not become a URL parser.
- Any future HTTPS universal-link work must add associated domains, publish and validate AASA, and update the share URL policy deliberately.

## Non-Goals

- No backend, hosted preview pages, or server-side playlist sync for Phase 12.
- No analytics/tracking parameters in shared URLs.
- No marketplace, pricing, listing, offer, or transaction-history links.
